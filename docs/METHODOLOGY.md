# 方法论与模型说明

本文件解释本工具背后的基金分析方法、各项指标的含义、策略规则的依据，以及 QDII「时差估算」模型的推导、
假设与局限。目标是让每一条「建议」都**可追溯、可解释、可调整**，而不是黑箱。

> 再次强调：以下是对**公开、通用**的基金/指数投资方法的工程化实现，是量化参考，**不构成投资建议**。

---

## 1. 整体思路：核心—卫星 + 估值纪律

你的画像是「**美股 QDII 为主（核心）、A 股为辅（卫星/分散）**」。对这种组合，业界常用的稳健框架是：

- **核心仓位用宽基指数 + 定投**：长期持有标普500 / 纳指100 等宽基，靠定投平滑成本（「微笑曲线」）。
- **用估值纪律决定定投力度与止盈**：低估多投、高估少投甚至止盈，避免在高位重仓、在低位恐慌。
- **用资产配置/再平衡控制风险**：不让单一市场（尤其你高度集中的美股）权重无限膨胀。

本工具就是把上述纪律自动化、量化、每日提醒。

## 2. 指标定义（`indicators.py`）

| 指标 | 含义 | 用途 |
|---|---|---|
| 移动均线 MA20/60/120 | 近 N 日净值均值 | 判断中短期趋势（多头/空头排列） |
| RSI(14) | 相对强弱，Wilder 平滑，0~100 | >75 超买（偏热）、<30 超卖（偏冷） |
| 最大回撤 MDD | 区间内从峰值到谷值的最大跌幅 | 衡量「最坏情况」风险承受 |
| 年化波动率 | 日收益标准差 × √252 | 衡量波动风险 |
| 夏普比率 | （超额年化收益）/（年化波动） | 单位风险的回报，越高越好 |
| 净值分位 | 当前净值在近 ~2 年净值序列中的百分位 | **估值高低的近似**（见下文说明） |
| OLS 回归 | 基金日收益对指数日收益的一元回归 | 估计 beta（敏感度），供时差估算 |

**关于「净值分位」作为估值代理**：最严谨的估值是指数的 PE/PB 百分位，但美股指数的免费 PE 历史不易稳定获取。
本工具退而用**净值价格分位**作为估值高低的近似——它能反映「现在是不是处于近两年相对高/低位置」，简单稳健；
缺点是牛市中价格持续新高会一直显示「高分位」。若你能提供权威的 PE/PB 百分位，可在后续接入替换，规则不变。

## 3. 策略规则（`strategy.py`）

每条规则产出一个方向票 `vote`（正=偏多，负=偏空），汇总成「信号分」，再映射到操作建议；其中**硬触发**
（已达止盈线、回撤止盈）会强制至少减仓。所有阈值见 `config/settings.yaml`，可按风险偏好调整。

### 3.1 估值分位定投（低买高卖的纪律）
- 分位 < `low_percentile`（默认 20%）→ +1.5：偏低，**适合定投/分批买入**。
- 分位 > `high_percentile`（默认 80%）→ −1.5：偏高，**警惕回调**。
- 思想来源：指数基金的「估值定投/低估买入、高估卖出」方法（如《指数基金投资指南》一类的低估值定投理念）。

### 3.2 目标止盈法（硬触发）
- 持仓收益 ≥ `take_profit_target`（默认 30%）→ 提示**分批止盈**。
- 思想：设定明确的止盈目标，达到即兑现一部分，避免「坐电梯」。

### 3.3 回撤止盈法（硬触发）
- 在**盈利状态**下，从阶段高点回撤 ≥ `trailing_dd_after_profit`（默认 10%）→ **保护利润止盈**。
- 思想：用回撤而非固定点位止盈，让利润奔跑、又不至于回吐过多。

### 3.4 止损警戒
- 持仓亏损 ≤ `stop_loss`（默认 −20%）→ 提示**复核基本面**。
- 注意：宽基指数**定投**通常**不主张止损**（越跌越是积累便宜筹码）；该信号主要针对行业/主题/主动型卫星仓位，
  措辞上也只是「警戒+复核」，不强制卖出。

### 3.5 趋势/动量（辅助，不主导）
- 均线多头排列（净值 > MA20 > MA60）→ +1；空头排列 → −1。
- RSI 超买 → −1；超卖 → +1（超卖往往是定投良机）。

### 3.6 再平衡（组合层，`portfolio.py`）
- 某基金当前权重偏离 `target_weight` 超过 `rebalance_band`（默认 5pct）→ 提示**减/加仓回到目标**。
- 另外对**单一资产占比 > 70%** 给出集中度提醒（针对你美股占比高的情况）。

### 信号分 → 操作映射
| 信号分 | 建议（定投中 / 非定投） |
|---|---|
| ≥ +1.5 | 加大定投 / 分批买入 |
| +0.5 ~ +1.5 | 继续定投 / 持有 |
| −0.5 ~ +0.5 | 持有观望 |
| −1.5 ~ −0.5 | 暂停定投 / 持有 |
| ≤ −1.5 | 减仓止盈 |
| 触发硬止盈 | 至少减仓；若整体很弱→考虑卖出 |

## 4. QDII「T+时差」收益估算模型（`estimate.py`）

### 4.1 要解决的问题
国内 QDII 基金净值是 T+1/T+2 公布的：美股今晚（北京时间凌晨）收盘后，对应净值要过 1~2 个交易日才更新。
于是你「看到的净值」滞后于真实价值。我们要用**已经发生**的美股涨跌，估出基金的「应有净值」。

### 4.2 模型
对跟踪指数 *I* 的 QDII，单个交易日的基金收益近似为：

```
r_fund ≈ alpha + beta · r_index   ( + r_fx ，若未做汇率对冲 )   − fee_daily
```

- `beta`：基金对指数的敏感度。纯指数基金 ≈ 1；可写死或用历史净值对指数日收益做 OLS 回归（`auto`）。
- `alpha`：截距，通常很小。
- `r_fx`：人民币兑美元当日变动。未对冲时，美元升值利好持有美元资产的国内投资者，故叠加。
- `fee_daily`：年综合费率 / 252。

**待体现收益**：把「最近 `lag_days` 个指数交易日」的 `r_index` 视为尚未反映到最新公布净值，逐日按上式换算成
`r_fund`，再复利：

```
累计待体现 = Π(1 + r_fund_i) − 1
应有净值   = 最新已公布净值 × (1 + 累计待体现)
```

**误差带**：用历史回归残差的标准差 `σ_resid`，给出约 ±1 个标准差的区间 `σ_resid · √(天数)`（假设各日残差近似
独立）。这提醒你估算值是一个**区间**而非定数。

### 4.3 关键假设
1. 基金主要被动跟踪某个可观测指数（对主动 QDII 偏差更大）。
2. `lag_days` 正确刻画了「净值滞后指数多少个交易日」。
3. beta/alpha 在估算窗口内大致稳定。
4. 汇率影响线性叠加、未对冲部分为 100%（实际可能部分对冲）。

### 4.4 如何校准（建议做一次）
- **lag_days**：挑一天美股明显大涨/大跌，记下指数涨幅；观察你的基金净值在**第几个交易日**反映出这笔涨跌，
  差几天就填几。
- **beta**：纯宽基指数基金填 `1.0` 即可；不确定就填 `auto`，程序会用历史净值回归（并把 beta 夹在 0.2~2.5 的
  合理区间，避免离谱值）。
- **currency_hedged**：查基金是否做汇率对冲，多数美股 QDII 未对冲 → `false`。

### 4.5 局限（务必知悉）
- 指数成分调整、汇率剧烈波动、基金现金仓位与申赎冲击、跟踪误差、分红除权等都会造成偏差。
- 对**主动管理型** QDII（非纯指数）误差更大。
- 节假日错位（中美假期不同）会让某天的「滞后天数」临时偏移。
- 它是**估算**，用于「心里有数」，不要据此做精确的套利或杠杆决策。

## 5. 参考的方法与资料（一般性）

本工具实现的是这些被广泛讨论的通用方法，便于你延伸阅读：

- **指数基金 & 低估值定投**：宽基指数长期持有、用估值（PE/PB 百分位或价格分位）决定定投力度与止盈
  （代表性读物如《指数基金投资指南》等大众投资读物的低估值定投理念）。
- **定投与「微笑曲线」**：分批买入平滑成本，下跌期积累份额、回升期兑现收益。
- **止盈方法学**：目标止盈、回撤（移动止盈）、估值止盈三类常见做法。
- **资产配置与再平衡**：经典的股债/多市场分散与定期再平衡，控制单一资产风险（对你美股集中尤为重要）。
- **风险度量**：最大回撤、波动率、夏普比率等组合风险收益指标。

> 这些是公认的通用框架；具体阈值（30% 止盈、10% 回撤、20%/80% 分位等）只是常见默认值，
> **请结合自身风险偏好在 `config/settings.yaml` 调整**。本工具不替代你的独立判断。
